# v0.3.7 MarketProp Command Center Polish

## Objetivo
Mejorar el Command Center manteniendo el diseño MarketProp y sin eliminar funciones útiles.

## Se agregó
- KPIs más inmobiliarios.
- Funnel comercial: alcance → perfil → WhatsApp/DM → visitas.
- Quality Gate más visible.
- Señales por propiedad.
- Mejores formatos por objetivo.
- Mejores horarios mock.
- Alertas inteligentes.
- Insights accionables.

## Regla
No se adopta el diseño del dashboard externo. Solo se extrae lógica útil.
