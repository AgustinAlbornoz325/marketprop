# Reglas de consolidación MarketProp

1. Mantener diseño MarketProp aprobado.
2. No adoptar diseños externos.
3. Extraer lógica útil de referencias externas, no copiar estética ni marca.
4. No eliminar módulos útiles.
5. Toda nueva versión debe agregar sin romper lo anterior.
6. Probar antes de guardar en Git.
7. Documentar decisiones en `docs/DECISIONS.md`.
